이 레포의 **열려있는 이슈 목록**을 보여줘. 이슈를 읽고 요약만 하는 명령이다 — 코드는 건드리지 말 것.

## 1. 목록 가져오기

```
gh issue list --state open --limit 50 --json number,title,labels,milestone,assignees,updatedAt
```

`gh` 가 PATH 에 없으면 `& "C:\Program Files\GitHub CLI\gh.exe"` 로 호출한다.

인자(`$ARGUMENTS`)가 있으면 그걸로 좁힌다:

- 마일스톤 이름처럼 보이면 → `--milestone "$ARGUMENTS"`
- 라벨 이름처럼 보이면 → `--label "$ARGUMENTS"`
- 애매하면 → `--search "$ARGUMENTS"`

한 번 시도해서 결과가 0건이면 다른 방식으로 한 번 더 시도해보고, 그래도 없으면 "없다"고 말한다.

## 2. 출력

**마일스톤별로 묶어서** 보여준다. 마일스톤 없는 건 맨 아래 `마일스톤 없음` 으로.
마일스톤 그룹은 due date 가 빠른 순, 그룹 안에서는 이슈 번호 오름차순.

각 줄 형식:

```
#10  가로모드                      (라벨) @담당자  · 3일 전
```

- 라벨·담당자는 없으면 생략한다. 빈 괄호를 남기지 말 것
- `updatedAt` 은 "3일 전" 같은 상대 시간으로 (오늘 날짜 기준)
- 제목은 그대로. 번역하거나 줄이지 말 것

마지막에 한 줄 요약: 총 몇 건, 마일스톤별 몇 건.

## 3. 하지 말 것

- 이슈 본문을 일일이 `gh issue view` 로 열지 말 것 — 목록만 필요하다
- 우선순위를 임의로 매기거나 "이것부터 하세요" 같은 추천을 붙이지 말 것. 물어보면 그때 답한다
- 브랜치를 따거나 구현을 시작하지 말 것 — 그건 `/work <이슈번호>` 가 할 일이다
